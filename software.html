Appendix A. Software and web tools

J. Majumdar1

1 Astronomical Observatory, University of Warsaw, Al. Ujazdowskie 4, 00-478 Warszawa, Poland

ABSTRACT

Code written along the way, released in the hope that it saves someone else an afternoon. Interactive web applications are listed in Sect. A.1 and code repositories in Sect. A.2. More is on GitHub.

A.1.Web applications

BlazarInfo
blazarinfo.streamlit.app. Quick-look information on blazars.
ZTF LC and PSD
ztf-lc.streamlit.app. Zwicky Transient Facility light curves and their power spectral densities.
